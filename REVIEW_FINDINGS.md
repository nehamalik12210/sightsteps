## Original eight reviewer findings — final disposition for submission (25 November 2026)

1. F-01 — No-match reassurance: FIXED / regression guarded. English and Hindi copy explains the limited scope of predefined patterns and that no match does not rule out a concern. The audit rejects “good sign” reassurance.
2. F-02 — Amsler success wording: FIXED / regression guarded. UI says “Activity Complete”; the activity records only participant-flagged areas and explains that no flags do not rule out a problem. The audit rejects screening-completion/result labels.
3. F-03 — Amsler physical size: PARTIALLY MITIGATED; DEVICE VALIDATION OPEN. The 85.6 mm reference-card procedure and two-dimensional viewport-fit guard remain. New bilingual copy states that matching is approximate and does not independently verify physical display scale, browser zoom or screen viewing setup. Physical scale, viewing distance and tap accuracy remain unvalidated across real devices.
4. F-04 — Amsler centre marker: SOURCE GEOMETRY VERIFIED; DEVICE RENDERING OPEN. CSS centres the marker at 50%/50% with translate(-50%, -50%) within the grid container. Real-device rendered geometry has not been independently verified.
5. F-05 — Low-light / outdoor_time: VERIFIED NOT AN ISSUE IN CURRENT RULES. The low-light rule uses explicit low-light context and the reported night-vision response, not outdoor-time as a proxy. The driving-context rule uses context belonging to that specific experience. Regression tests protect source/context scoping.
6. F-06 — Clinical-language allowlist: IMPROVED; HUMAN REVIEW OPEN. Safe exceptions are tied to the matching forbidden occurrence; a disclaimer elsewhere cannot excuse later unsafe copy. New uppercase, punctuation-separated mixed safe/unsafe, Hindi unsafe-claim, neutral Hindi and JSX extraction fixtures pass. This remains a lexical safeguard, not expert review.
7. F-07 — Audit coverage: FIXED / coverage regression guarded. The audit recursively discovers/parses all JSX under src, covers visible nodes/attributes/expressions and bilingual/generated copy, and tests nested-component discovery. Current scan: 23 JSX files / 2,777 fragments.
8. F-08 — Clinician Brief provenance: FIXED. Report discussion topics distinguish the participant responses linked to a topic; Clinician Brief labels “Your responses contributing to this pattern”; Evidence Pathways expose original answer IDs and distinguish participant-reported answers from generated relationships.

External release gate: First formal expert review by a licensed optometrist or ophthalmologist remains pending. SightSteps is not clinically validated or clinician-approved.
